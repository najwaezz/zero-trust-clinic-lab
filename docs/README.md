## Checklist avant d'ajouter le rapport
- [ ] Autorisation de l'entreprise d'accueil et de l'encadrant obtenue
- [ ] Nom du client remplacé par « Clinique X » partout (titre, texte, tableaux, figures, en-têtes PDF)
- [ ] Topologie réelle (Figure 2) supprimée ou remplacée par un schéma générique
- [ ] Tableaux de constats/actifs du client réel anonymisés ou retirés
- [ ] Résultats du scan Nmap du réseau réel non inclus
- [ ] Dédicace, remerciements et noms de personnes retirés
- [ ] QR code TOTP (Figure 19) masqué
- [ ] Hostnames ou noms personnels floutés si souhaité
- [ ] Métadonnées du PDF nettoyées (auteur, titre, commentaires)
